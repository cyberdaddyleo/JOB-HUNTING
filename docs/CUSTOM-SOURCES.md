# 自定义公开招聘目录

公开页面连接器可以收录人社官网、高校人事处、企业招聘官网中直接呈现在 HTML 里的招聘公告。每次只读取配置的目录页，以及该域名的 `robots.txt`；最多保留 30 条同域名公告，不翻页、不抓取详情、不登录、不执行网页脚本。

它适合已有公告列表的公开页面。登录后的查询系统、只有 JavaScript 加载的职位列表、验证码页面、直接下载的表格，以及禁止自动读取的站点，需要使用官网入口或手动文件导入。

## 来源配置

填写来源名称、HTTPS 目录网址和分类；地区可以留空。分类支持 `人社官方招聘`、`高校招聘`、`企业招聘`。名称与分类由用户填写，不代表系统验证了该域名的机构身份；添加前请从机构官方网站核对招聘入口。

```json
{
  "name": "某大学人事处 · 公开招聘",
  "homepage": "https://hr.university.edu.cn/recruitment/list.htm",
  "category": "高校招聘",
  "region": "上海"
}
```

上述网址仅演示字段格式。服务端调用 `await validatePageSource(input)` 后，创建独立随机 ID 的 `public-page` 来源，默认启用，最短同步间隔为 60 分钟。配置名称最多 100 字符、网址最多 2000 字符、地区最多 160 字符。地区是来源标签，不能据此确定每个公告中所有岗位的实际工作地点。

连接器接口：

```js
import { validatePageSource, fetchPageSourceJobs } from './server/page-source.js';

const source = await validatePageSource(input);
const notices = await fetchPageSourceJobs(source);
```

仅测试或受信任的服务端代码可注入解析器：`validatePageSource(input, { lookup })`、`fetchPageSourceJobs(source, fetchImpl, { lookup })`。`lookup(hostname, { all: true, verbatim: true })` 必须返回 `{ address, family }` 数组。前端请求不能设置网络实现、DNS 解析器或内置来源身份。

## 收录结果与边界

每条记录保留公告标题、原文链接、来源名称、`sourceId`、由 URL 生成的稳定 `externalId`。只有单条公告附近出现明确、完整、无歧义的年月日，才填写发布时间；月日、冲突日期、无效日期或标为截止时间的日期保持空白。

所有结果都标记为 `recordType: "announcement"` 和 `requiresReview: true`。招聘单位字段暂用来源名称；公告可能包含多个单位或多个岗位，请打开原文核对。学历、经验、薪资、行业、截止时间与招聘邮箱保持未知；不会根据标题推断资格，也不会把目录上的联系方式当作投递邮箱。申请方式始终提示到官网核对并手动申请。

解析器排除导航、登录注册、模板、常见招聘制度与流程说明、拟聘结果公示、外域名链接及重复链接。它不能保证通用规则适配每个站点，也不保证目录中的公告仍在招聘。没有识别到可核对公告时会明确报错，不会伪造记录或将空页面报告为成功。

## 已验证的内置高校来源

[复旦大学人事处 · 派遣制用工公开目录](https://hr.fudan.edu.cn/15370/list.htm)已于 **2026-11-14** 通过网页查询与连接器实际请求验证：目录返回 HTTP 200，`robots.txt` 返回 HTTP 404，默认连接器取得 **14 条**公告。最近两条分别为技术转移中心专员、科研助理招聘，发布时间均为 2026-11-13；全部保留为待核对的原始公告。

该来源的内置 ID 为 `cn-fudan-public`，地区标签为上海，默认启用。它仅覆盖复旦该公开目录的当前一页，不代表全校所有招聘类别。其他高校与企业需要分别添加已核对的公开目录；增加来源不会自动发现该机构所有招聘系统。

调研时也检查了南京大学人力资源处与其人才招聘网。人力资源处的旧招聘目录包含历史记录；现行人才招聘网的 `robots.txt` 请求返回向 HTTP 页面的重定向，因此没有把它加入本连接器的已启用推荐来源。不会绕过此限制。

## 网络保护

自定义网址只允许标准 443 端口的 HTTPS 公开域名，不允许账号密码、IP 地址、本机或保留域名。保存来源和读取页面时都会检查 DNS 的全部返回地址，拒绝任何本地、私有、链路本地、共享地址、文档地址、基准测试地址、IPv4 映射及非公网 IPv6 地址。自定义来源的默认 HTTPS 传输把连接固定到已验证的地址，保留原主机名的 TLS 证书验证，避免校验后 DNS 重绑定。

每个请求最多 18 秒、响应体最多 2 MB。响应流也按字节累计限制；不跟随重定向，不读取登录或 HTTP 403 页面。先检查 `robots.txt`，禁止的目录停止同步；robots 返回 404/410 时视为未提供规则，其余错误会中止读取。

固定内置来源采用与其他内置官方连接器相同的正常网络路径，以兼容本机代理。这个例外只匹配代码中不可变的 **来源 ID + 类型 + 完整 HTTPS 目录网址** 三元组，且仍只请求固定域名的 robots 与目录、遵守 robots/超时/体积/重定向规则。自定义来源即使复制了内置网址，也使用独立 ID 并接受完整 DNS 检查，不能获得该例外。

如果自定义来源提示解析到非公网地址，而本机代理启用了 Fake-IP DNS，应检查代理的 DNS 设置。连接器不会把 `198.18.0.0/15` 等保留地址视为公网地址，也不会为了完成同步而放宽检查。

## 验证

`tests/page-source.test.js` 使用注入的 DNS 与响应，不依赖外网。它覆盖配置约束、私网与混合 DNS 拒绝、二次 DNS 检查、固定来源身份隔离、robots 拒绝、HTTP 403/重定向、流式 2 MB 限制、超时、同域名链接去重、30 条上限、日期歧义和不推断资格。

```sh
node --test tests/page-source.test.js
```

实站结果会随官网更新。需要重新验证时，调用 `fetchPageSourceJobs(recommendedPageSources[0])`；验证只读取公开目录，不会报名或发送邮件。
