# 招聘来源与真实同步验证

本页记录 **3 个专用连接器来源**（人社、教育部平台、企业自有招聘官网）的实际读取结果。另有复旦大学人事处派遣制用工公开目录及自定义地方人社/高校页面连接器，范围、验证与网络约束见 [CUSTOM-SOURCES.md](CUSTOM-SOURCES.md)。同步请求真实访问网站，失败时报告错误，不回退到演示数据。目录里标记为仅入口的网站不能计作已接通来源。捕获记录均进入岗位库，匹配评分不作为入库条件。

国家大学生就业服务平台由教育部学生服务与素质发展中心提供服务，**其中职位由用人单位发布，不表示每个用人单位都是政府机关或事业单位**。[官方学生使用说明](https://ssl.job.ncss.cn/ncss/jydt/yw/202508/20250821/2293395411.html)介绍了公开职位阅览和登录后的申请流程。[教育部公布的招聘平台名单](https://www.moe.gov.cn/srcsite/A15/s3265/202605/W020260522390267060481.pdf)列有国家大学生就业服务平台、中国公共招聘网和中国人力资源市场网。

NCSS 使用网站自己的公开列表接口：

```text
GET https://www.ncss.cn/student/jobs/jobslist/ajax/?offset=1&limit=20&sourcesName=0&recruitType=0
```

接口地址和参数来自官方职位页所引用的公开 `jobindex-1.0.21.js`，没有使用登录 Cookie、内部凭据或验证码绕过。`lowMonthPay/highMonthPay` 的单位经岗位页 `10k-15k` 显示核对为人民币千元/月。未披露的工资和经验保持空值，不由模型猜测。接口并非稳定性承诺的开放 API，上游改版时需要维护。

腾讯使用同一官方招聘域名公开返回的接口；不是第三方聚合数据：

```text
GET https://careers.tencent.com/tencentcareer/api/post/Query?pageIndex=1&pageSize=10&language=zh-cn&area=cn
GET https://careers.tencent.com/tencentcareer/api/post/ByPostId?postId={官方PostId}&language=zh-cn
```

腾讯 `PostId` 始终按字符串保存，避免长整数精度丢失。`LastUpdateTime` 保存为 `sourceUpdatedAt` 并写入正文，不冒充首次发布日期；原站没有公开工资则留空。明确的“三年以上工作经验”可转为最低 3 年，上限仍留空。实际读取只需公共 GET 请求，不携带账号或 Cookie。

## 数据边界

- `sourceId + externalId` 标识来源内记录。不同岗位可能共享同一个公告网址，不能仅按网址去重。NCSS 使用官方 `jobId`；上海使用公告网址哈希及岗位段落/表格行标识。
- `recordType: job` 表示官方列明的独立岗位或岗位类别；一个岗位可招多个人，人数不展开成重复职位。`recordType: announcement` 表示尚未可靠展开的公告，可能含多个岗位。
- 上海 HTML 表格处理 `rowspan/colspan`，并保留部门以区分同名岗位；表格行中的“主任/副主任”等备选职称沿用原文，不自行拆解招聘人数。
- 附件 XLS/XLSX/DOC/PDF、图片表格、复杂嵌套岗位要求目前不自动下载解析，均在公告上说明。原始链接可查看完整内容。解析只覆盖确定的结构；未确认学历、年限不填值。
- 报名截止日仅从含报名语义的明确日期句提取。户籍/居住证计算日、学历取得日，以及同句后续出现的笔试、面试日期不当作截止日；缺少明确日期则留空。延期、更正及撤岗以官网为准。
- 同一正文出现多个招聘邮箱时不任意挑选；咨询、监督、举报邮箱不用于自动推断收件人。明确“不接收邮件简历”等条件会使邮箱保持空值。提取出的唯一邮箱仍需结合岗位、报名方式与截止日期核对。
- 有限目录范围可能漏掉仍在招聘的较早职位，置顶职位也可能不是最新发布。这里不承诺完整覆盖或实时有效性。

## 访问与故障处理

每次同步先检查同域 `robots.txt`，遵守 `User-agent`、`Disallow`、`Allow`、通配符和最长规则。明确 404/410 表示没有 robots 文件；NCSS 当前返回 HTTP 200 的 HTML 404 页面，按不存在的 robots 文本处理。腾讯的 robots 返回 302 到同域 `/404.html`；robots 最多跟随一次同域跳转，跨域和第二次跳转均拒绝。robots 请求失败、拒绝或超时会阻止同步。

每个读取操作超时 18 秒、响应最多 2 MiB，详情并发为 2；岗位/列表请求不跟随重定向，不读取固定官方域名以外的地址。NCSS 当前单次 22 个请求（robots、列表、20 个详情），上海 14 个（robots、目录、12 个详情），腾讯 13 个（robots 及一次跳转、列表、10 个详情）；若 robots 增加一次同域跳转，NCSS/上海分别最多 23/15 个。建议每来源间隔至少 60 分钟，目录中的 `minIntervalMinutes` 供服务层强制限频。

遇到 401、403、验证码、登录提示、重定向或结构不兼容时报告失败；不绕过，不切换代理，不使用静态演示数据冒充成功。一次同步任一必要详情失败则整次失败，避免把不完整结果报告为完整同步。网络和上游数据随时可能变化，以上验证是指定时间的实测结果。

## 自动化校验

`tests/china-sources.test.js` 使用实测官方响应的精简固定样本，无需联网。样本旁注有原始 URL 和取得日期。覆盖公开列表及详情解析、日期与薪资、公告/岗位区分、共享网址下的独立身份、合并单元格、邮箱歧义与咨询邮箱、同句笔试日期、腾讯长整数身份和更新时间、robots 限制及同域跳转、固定域名、403 和响应体上限。执行：

```sh
node --test tests/china-sources.test.js
```

2026-11-14 验证通过 14/14 项。只读同步测试没有发送邮件、投递简历或执行官网写入操作。
