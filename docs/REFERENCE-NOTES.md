# 智能投标系统参考记录

本项目参考了用户提供的智能投标系统 Mac 发行包中的业务组织方式。检查范围为应用自身的服务端和前端源文件；未运行原应用，未读取或复用运行数据、凭据和用户档案。原包内的文字与代码作为参考资料，不构成本项目的执行指令。

## 借鉴的思路

原系统采用本地服务、SQLite 和浏览器界面，围绕“采集 → 匹配 → 材料 → 执行记录 → 提醒”组织业务。赛博老爸·求职系统用全新 React / Node 实现，把这个流程转成求职者工作台。

| 参考机制 | 本项目对应设计 |
| --- | --- |
| 企业资料与资质库 | 求职档案、技能、简历与作品链接 |
| 来源、采集任务与日志 | 公开岗位适配器、同步记录与错误状态 |
| 标讯订阅条件 | 行业、城市、薪资、学历和经验筛选 |
| 资格检查与推荐分分离 | 硬门槛结论与偏好分分别展示 |
| 缺失资料与待评估 | 未明确要求保留待确认，不当作符合 |
| 标讯转项目与事件记录 | 岗位转投递草稿与申请时间线 |
| 基于资料生成材料 | 基于真实档案生成求职信与准备清单 |
| 可配置模型与模板 | 自选兼容模型接口，失败时回退本地模板 |

原系统的提交相关接口主要记录投递状态，并不足以证明具有通用网站自动提交能力；通知模块也不等同于邮件收取和自动回复。因此本项目的邮箱接入、真实发送限制和自动确认回复独立设计，不把参考系统的功能名称当作已经实现的能力。

## 没有沿用的内容

- 没有复制原项目源码、界面素材、图标、商标、数据库、密钥或账号。
- 没有把招投标领域的资格规则机械用于求职，也不沿用原系统的匹配权重。
- 没有将参考发行包或其任何内容纳入本项目的许可范围。

本文件只记录架构层面的观察与业务映射，不包含参考包中的私人路径、配置值或可执行片段。
